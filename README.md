## 📌 Overview

A **pixel-accurate front-end clone** of Amazon's homepage, built entirely with vanilla HTML5 and CSS3. This project demonstrates proficiency in real-world UI replication — including complex layouts, navigation bars, hero banners, product grids, and a fully styled footer.

> **Purpose:** Front-end skills showcase — demonstrating layout mastery, CSS Flexbox/Grid, and semantic HTML structure.

---

## ✨ Features

- 🔝 **Sticky Navigation Bar** — Logo, search bar with category dropdown, account links, cart icon
- 🎯 **Hero Banner Section** — Full-width promotional banner with CTA overlay
- 🗃️ **Product Grid** — Multi-column product category cards with hover effects
- 🔗 **Multi-level Footer** — Links organized across columns, matching Amazon's structure
- 📱 **Responsive Layout** — Adapts across desktop and tablet viewports

## 🚀 Getting Started

No build tools required. Simply open in your browser:

```bash
# Clone the repo
git clone https://github.com/PG1611Bcode/Amazon-Clone.git
cd Amazon-Clone

# Open directly in browser
start index.html        # Windows
open index.html         # macOS
```

Or use a local development server:

```bash
# With VS Code Live Server extension, or:
npx serve .
```

Navigate to `http://localhost:3000` (or the port shown in your terminal).
